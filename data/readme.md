# Portfolio Dataset

Due to GitHub's file size limits for browser uploads, the full dataset used for this loan risk scorecard analysis is hosted on Google Drive.

* **📥 Download Full Raw Dataset:** https://drive.google.com/file/d/1zEOJ2xjCu8PDcVRXiXrlJHbTdM5zsTVC/view?usp=sharing

## Dataset Overview
- **File Contents:** Individual borrower records, demographic splits, credit metrics, and loan default history (`0` for safe, `1` for default).
- **Usage:** This dataset powers the SQL risk scorecard queries and Excel dashboards found in this repository.
